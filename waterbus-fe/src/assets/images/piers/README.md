# Pier photos

Put the photos of each pier here, named after the station code in lowercase:
`st01.jpg` is the first photo of ST01, `st01-2.jpg`, `st01-3.jpg`, … are the next ones
(`.jpg`, `.jpeg`, `.png` and `.webp` work). Clicking the pier on a map shows them as a gallery; a
pier without a photo shows a placeholder. Only add photos you own or have the right to use.

## Photos in this folder

Commons user Pk.over. Credit is not required, but the sources are kept here:

so they show the placeholder until photos are added.
